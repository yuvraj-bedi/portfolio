## 🔬 Overview

Personal digital laboratory and engineering proving ground of **Yuvraj Bedi**, 2nd-year Computer Science undergraduate at **Bennett University** (2025–2029).

This portfolio rejects the standard template paradigm, approaching software engineering as an active research observatory. It showcases deep curiosity across core computational systems, memory models, object-oriented abstractions, algorithmic problem solving, and modern high-performance reactive web architecture.

## 🧭 System Structure

- **`01 INTRO`**: Digital Observatory with interactive 3D Three.js particle lattice responding dynamically to cursor physics.
- **`02 ABOUT`**: Computational rigor, low-level memory mechanics in C++, OOP in Java, discrete math, and engineering philosophy.
- **`03 WORK`**: Architectural proving ground featuring speculative and active systems builds (`EXP_01`, `EXP_02`, `EXP_03`).
- **`04 LAB`**: Active radar tracking university core coursework alongside exploratory research inquiries (AI/ML, Neural Networks, GPU Compute).
- **`SYS INSTRUMENTATION`**: Technical capability matrix covering C++, Java, Python, Web, SQL/MySQL, Git, VS Code, and CS Fundamentals.
- **`05 JOURNEY`**: Academic milestones, course roadmaps, and telemetry at Bennett University.
- **`06 CONNECT`**: Direct transmission line, verified GitHub repository links, and LinkedIn channels.

## 🛠 Tech Stack

- **Core Framework**: React 19, TypeScript
- **Bundler & Tooling**: Vite 8, Oxlint
- **Styling**: Tailwind CSS v4, Custom CSS Design System Tokens
- **Interactive 3D**: Three.js Algorithmic Lattice Points Canvas
- **Animation & Physics**: Framer Motion (`motion/react`), Lenis Smooth Scroll
- **Audio Engine**: Web Audio API Procedural Synthesizer
- **Icons**: Lucide React

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/yuvraj-bedi/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
